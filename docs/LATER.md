# Later
*These are ideas that are not in the current v1 scope, but can be implemented at any point, and will be updated accordingly*

## Play generation from natural language

- Allow coaches to describe plays or play suites with natural language, deliver a set of plays, including arts
- Play suites can be suggested based on current tendencies, strengths, and weaknesses

## Practice planning

- Based on recent game results, upcoming matchups, and overall team identity, plan practices for different aspects of the game
- Would have to either allow web searching from agent, or have pre-built library of practice components that are given hidden features corresponding to team's current state

## Video/film analysis

- Be able to identify plays and results without manual sideline logging
- Film would be more feasible as opposed to real-time game footage
- Could also be used to identify mistakes in play execution (ex. receiver lined up improperly, holding call on lineman, the specific missed read from the quarterback)
